Marine PGR v1.2.4

Ícones multirresolução gerados da imagem original de 1024 pixels.
Carregamento nativo de ícones pequenos e grandes no Windows conforme a escala da tela.
Identificação própria na barra de tarefas e nitidez com consciência de DPI.
Marca do cabeçalho redimensionada diretamente do original conforme a escala.
Executador de distribuição, compilação isolada, ZIP com executável e SHA-256.
Fluxo manual do GitHub Actions para gerar o pacote.
Publicação no GitHub não foi realizada.
